# Contributing

This project is built one substep at a time: **explain → show the exact command or file → run → interpret the output → checkpoint against the plan's *Done when*.** Every change reaches `main` through a pull request that passes the pipeline; every failure becomes an incident in `docs/field-notes.md` (cause → fix → lesson); every "why" becomes an ADR in `docs/adr/` with the alternative rejected.
